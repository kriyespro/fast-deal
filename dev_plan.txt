PropSurat — Multi-Broker Property Portal
Django SaaS Dev Plan
═══════════════════════════════════════════════════

GOAL: Multi-broker property portal with 5 roles
      Broker | Builder | Client | CityAdmin | GlobalAdmin
STACK: Django 5, Jinja2, HTMX, Alpine.js, Tailwind CSS

═══════════════════════════════════════════════════
PHASE 1 — Django Bootstrap (current)
═══════════════════════════════════════════════════
1.1  Create Django project (core/) + manage.py
1.2  Install dependencies → requirements.txt
1.3  Configure settings:
       - Jinja2 PRIMARY (all .jinja templates)
       - DjangoTemplates for /sd/ admin only
       - Static files, media files
       - SQLite dev DB
1.4  Create durga.py dev runner
1.5  Set up base URL routing
1.6  Create .gitignore

═══════════════════════════════════════════════════
PHASE 2 — Users App + 5-Role Auth
═══════════════════════════════════════════════════
2.1  Custom User model (email login, role field)
     Roles: CLIENT | BROKER | BUILDER | CITY_ADMIN | GLOBAL_ADMIN
2.2  Profile model (linked 1:1 to User)
2.3  Migrations → confirm → apply
2.4  Auth views: login, register, logout
2.5  Role-based register flow (choose role on signup)
2.6  Role-based redirect after login
2.7  Convert login.html + register.html → Jinja2
2.8  @login_required + role decorators

═══════════════════════════════════════════════════
