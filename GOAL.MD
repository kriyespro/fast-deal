# PropSurat — Goal

Build a multi-broker property listing portal that is easy for non-technical users.

- Home page and frontend polished and trustworthy
- Mobile-responsive design
- Simple flows a layman can use

## 5 Roles

1. **Broker** — list properties, manage leads
2. **Builder** — manage projects / units
3. **Client** — search, save, enquire
4. **CityAdmin** — approve listings & verify brokers in assigned city
5. **GlobalAdmin** — Mission Control platform ops
